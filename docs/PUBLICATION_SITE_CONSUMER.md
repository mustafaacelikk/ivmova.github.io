# Publication Site Consumer — 6C-2

TR-only yerel staging pilotu. Demo varsayılandır; publication modu NEXT_PUBLIC_IVMOVA_CONTENT_MODE=publication ile açık seçilir. Public verinin kaynağı .publication-local/current.json ve hash ile doğrulanan immutable release state’idir. Eksik/hatalı veri demo fallback yapmaz.

Sözleşme kopyaları contracts/publication-v2 altında; kaynak checkpoint checkpoint-public-site-analysis-v1 ve kaynak commit contract-manifest.json içinde sabittir. Validator şema byte checksum’larını embedded pin ile doğrular; bilinmeyen sürüm/ref/keyword reddedilir. Tam genel JSON Schema motoru değildir, pinned sözleşmelerin kapalı alt kümesini uygular.

Komutlar: npm run publication:import -- <mutlak-yerel-release-root>; npm run publication:rollback. Import root tek manifests/<export-id>.json ve yalnız UPSERT/RETRACT Story JSON dosyalarını içerir. Opsiyonel receipt.json varsa birebir doğrulanır; yoksa aynı detached receipt doğrulanmış byte’lardan üretilip internal kayda konur. Receipt gerçek deployment alındısı değildir.

TR-only; category mapping açık: Enerji/enerji, Enerji Piyasaları/piyasalar, Teknoloji/teknoloji, Mobilite/mobilite, İklim/iklim, Analiz/analiz. Unknown dil/kategori reddedilir. headline→title, standfirst→summary (null→boş), bodyMarkdown→body satır dizisi, storyId→id, ISO timestamps→ISO görünüm/sıralama. Alt kategori boş, priority=0/breaking=false, byline boş; yerel nötr SVG kullanılır. Yazar/önem/görsel kaynak kararı uydurulmaz. Kaynakların bütün beş alanı korunur.

FULL tam ve yetkili current set beyanıdır; current seti yeniden kurar, eski REMOVE/RETRACT fences korunur. Önceki aktif Story FULL içinde yoksa internal omission fence ve implicitRemovals kaydı oluşur; bu producer REMOVE proof’u gibi gösterilmez. Bu nedenle eksik/parsiyel liste FULL diye verilmemelidir. INCREMENTAL yalnız current varken uygulanır. generatedAt yüksek su işaretinden kesin yeni olmalı; run replay, slug kimlik çakışması ve eski/çelişkili revision reddedilir. Bu pilot tek güvenilir seri yerel importer içindir: manifestte expected base alanı yoktur; distributed delta-base fencing üretim için ayrıca gereklidir. Slug değiştirme aynı kimlik için reddedilir. REMOVE ve RETRACT sonrası UPSERT yeniden yayımlama pilotta fail-closed; yeniden yayımlama için ayrı yetkili lifecycle kararı gerekir.

UPSERT liste/detay/static params; RETRACT route’da güvenli notice fakat listelerde yok; REMOVE route/list/sitemap’te yok, internal tombstone kalır. Boş liste güvenli render edilir. ArticleBody yalnız mevcut Markdown alt kümesini kullanır ve ham HTML çalıştırmaz.

Store .publication-local dışında yalnız OS TEMP altındaki özel test store kabul edilir. Ancestor/entry symlink, extra file, path traversal/URL/absolute artifact path/backslash, BOM/duplicate JSON key, unknown/private field reddedilir. Üst sınır 1002 dosya/16 MiB input; ayrıca directory depth/entry limit vardır. Revision contentHash ile artifactSha256 farklıdır; manifest byte hash detached kayıttadır.

Exclusive local lock, immutable state/record staging, fsync/readback, rename ve tek current pointer dosyasının atomik replace’i kullanılır. En az previous ve tüm yerel kayıtlar saklanır. Başarısız import current’a dokunmaz; rollback previous state’e current fences’i yeniden uygular, high watermark/replay geçmişini korur. Hostile concurrent OS writer veya disk power-loss dayanıklılığı kanıtı değildir. Yalnız güvenilir kullanıcıya ait store kullanılmalıdır.

Publication build için NEXT_PUBLIC_IVMOVA_SITE_ORIGIN açık localhost staging origin’i olmalıdır; production origin’e pilotta izin verilmez. IVMOVA_PUBLICATION_STORE yalnız private build girdisidir. Public bundle yalnız explicit normalize public view taşır; receipt/run/manifest hashes/audit/fences taşınmaz. Generator/consumer/store public içine kopyalanmaz. Supabase credential gerekmez.

Demo veri app/data.ts içinde korunur. next.config build öncesi yalnız seçili modu hazırlar; client/server/header/category/sitemap/detail ortak site-news üzerinden beslenir. Main push workflow deploy tetikler; pilot için push/deploy yapılmaz. npm run test:publication-consumer ve npm run test:publication-builds sentetiktir; dış ağ kapalıdır, Next compiler loopback IPC’si açıktır; build runner izole TEMP kopyalarında çalışır ve mevcut out/.next’ı korur. Hosted staging, DNS ve production lifecycle/recovery bu pilotun dışındadır.
